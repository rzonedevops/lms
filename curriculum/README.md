## Learning Path

### Recommended Order:
1. **Start with Fundamentals** - Understand the core RégimA Zone concept
2. **Move to Zone Training** - Learn products in order: Cleansers → Eye Care → Daily Care → Treatments
3. **Advance to SpaZone** - Professional treatments and protocols
4. **Reference Ingredients** - Deep dive into active ingredients as needed
